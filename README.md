# Movie App

A responsive Single Page Application (SPA) for discovering and exploring movies, built with **HTML, CSS, and Vanilla JavaScript**.

## Features

- **Movie Search:** Search for movies by title.
- **Movie Details:** View detailed information about each movie.
- **Dynamic Content:** Browse and display movie data dynamically without reloading the page.
- **Single Page Navigation:** Navigate between different views without full-page refreshes.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Interactive UI:** Smooth user interactions and dynamic page updates.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- REST API

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/miladamooii/movie-app.git
```

### 2. Navigate to the project directory

```bash
cd movie-app
```

### 3. Run the application

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
